# JSTQB AL-TM 学習アプリ（テスト配布）

JSTQB Advanced Level テストマネージャ試験の学習アプリです。**テスト中のため、予告なく更新・公開停止することがあります。**

👉 **https://hirooki-iwamoto.github.io/jstqb-al-tm-app/**

## 使い方

上のリンクを開くだけです。インストールは要りません。スマートフォンのブラウザでそのまま使えます。

- **学習の記録は、お使いの端末の中だけに保存されます。**サーバーへは何も送られません
- 端末やブラウザを変えると、記録は引き継がれません（設定 →「書き出す」で持ち出せます）
- ブラウザの履歴やサイトデータを消すと、学習の記録も消えます
- 通信しないので、機内モードでも動きます

## いま入っているもの

- 問題 53問（学習目標25 / 48）
- 演習（5・10・15・20・25問）／ハーフ模試（25問・60分）
- 章・節・学習目標・誤答の型による絞り込み
- 合格ラインまでの距離の予測、誤答の型ごとの弱点分析

問題数はまだ試験1回分ほどです。一通り触るには足りますが、解き進めると在庫が尽きます。
